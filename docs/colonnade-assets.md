# Colonnade и новые портреты

Блок направлений адаптирован из предоставленного пользователем `colonnade.zip`, файл `colonnade.html` (GetLayers Colonnade). Сохранены расширяющиеся колонки, вход изображения снизу и выход вверх, управление наведением, нажатием, фокусом и стрелками. Вместо абстрактных градиентов использованы фотографии клуба; стили ограничены компонентом. Мобильный вариант — вертикальный аккордеон.
