# Расписание тренера и учёт часов

Кабинет тренера открывается на `/trainer/schedule`. Основная навигация показывает личное расписание; создание и перенос занятий остаются в административном кабинете. Дополнительные ранее реализованные инструменты не удалены из API. При запросе расписания с `area=trainer` учитываются только занятия текущего тренера, включая аккаунты с несколькими ролями.

Администратор назначает или снимает роль тренера в разделе «Пользователи → Права тренера». Другие роли сохраняются; менять администратора или владельца таким способом нельзя. Профиль тренера создаётся автоматически. Пользователь входит заново после изменения роли. Снять роль при незавершённых программах или будущих занятиях нельзя.

`/admin/analytics` содержит два графика: подтверждённые часы по тренерам и заполняемость занятий по дням. Период ограничен 92 днями; границы календарных дат считаются по московскому времени. Заполняемость — отношение подтверждённых записей, посещений и неявок к вместимости опубликованных занятий за период. Это не доля занятости зала относительно часов его работы. Черновики, отменённые занятия и отменённые записи исключены. Дни без занятий показываются без процента.

Часы учитываются отдельно от расписания: администратор подтверждает фактическую длительность прошедшего занятия в минутах. По умолчанию подставляется длительность из расписания. Изменение длительности, включая ноль для несостоявшегося занятия, требует причины. Прошедшее время без подтверждения не попадает в отработанные часы и отображается как ожидающее подтверждения.

`TrainerWorkLog` содержит одну запись на занятие. Изменение заменяет её длительность, а не добавляет часы повторно. Версия записи предотвращает потерю параллельных правок. Изменения протоколируются в `AuditLog`; будущие, отменённые занятия и черновики учитывать нельзя. API чтения и записи доступен только ADMIN и OWNER. Ставки, зарплата и выплаты не рассчитываются.

- `GET /api/v1/analytics/trainer-hours?from=YYYY-MM-DD&to=YYYY-MM-DD[&trainerId=UUID]`
- `PUT /api/v1/analytics/trainer-hours/:sessionId`: `{ minutes, note, version }`, версия 0 для первого подтверждения.
